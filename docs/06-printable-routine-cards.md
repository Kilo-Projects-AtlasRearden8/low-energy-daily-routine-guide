# Printable Routine Cards

Printable cards you can cut out, tape to a mirror or fridge, and use on low-energy days.

## How to print

1. Open `site/cards.html` in your browser
2. Press Ctrl+P (or Cmd+P)
3. Choose "Print" and set Background graphics to ON
4. Select paper size Letter or A4
5. Cut along the lines

## Cards included

| Card | What it is for |
|------|----------------|
| One Task Today | Write your single task for the day |
| Gentle Schedule | Fill in your loose daily blocks |
| Energy Tracker | 1–5 ratings for morning, midday, evening |
| Rest Permission | A reminder that rest is allowed |
| Low-Energy Tasks | Blank space for your own easy tasks |

Print as many copies as you need. Use a pencil so you can reuse them, or print fresh each week.
